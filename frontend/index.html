Web Traffic Quality & SEO Diagnosis System

結合 GA4、GSC 數據與 Rule-based 診斷邏輯的 Marketing Analytics 報表系統

📌 作品集專案背景 (Portfolio Context)

本專案為個人公開作品集版本，重現實際工作中開發與維持的 Marketing Analytics 系統。為保護商業隱私，採去識別化假數據 (De-identified / Mock Data)，完整保留系統架構、正規化邏輯與分析視覺化。

Marketing Analytics SEO Diagnosis Engine URL Normalization FastAPI & ECharts

💡 核心解決痛點 (Key Analytical Pain Points)

  • 跨平臺數據割裂 (Cross-Platform Isolation)：整合 GA4 (造訪後互動：Views, Engagement, Duration) 與 GSC (搜尋前段：Impressions, Clicks, Position, Queries) 於單一視角。
  • 網址正規化清洗 (URL Normalization)：自動剝離廣告追蹤碼 (utm_*, gclid, fbclid) 並精確比對 GSC Canonical URL，解決跨平臺 Join 痛點。
  • Rule-based SEO 異常診斷：根據 YoY 點擊流失、排名下滑與 CTR 衰退計算 0~100 分 Anomaly Score，並自動標註診斷病徵標籤（如「高價值流量流失」、「排名衰退」、「高曝光低 CTR」）。
  • Snapshot 快照策略：背景任務預計算快照，消除即時發起 API 的數十秒延遲與 Quota 限制，達成秒級回應。

🎛️ 雙模式互動說明

📊 GA4 流量品質模式：展示整體流量來源、參與率、平均停留時間與產品小分類流量表現。

🔍 GSC 自然流量診斷模式：提供 Glassmorphism 暗色視覺，展示搜尋象限圖、關鍵字點擊/排名變動與頁面級 SEO 診斷明細。
